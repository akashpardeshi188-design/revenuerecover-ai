# RevenueRecover AI & Autonomous AI Growth Operating System

> **RevenueRecover AI** is the core B2B vertical SaaS product providing **45-second AI missed-call text-back**, **dormant customer reactivation**, and **unpaid invoice recovery** for home service contractors (HVAC, Plumbing, Electrical).
>
> The **Autonomous AI Growth Operating System** is the 25-agent digital marketing and sales company built around RevenueRecover AI to continuously discover, verify, enrich, score, personalize, contact, qualify, book demos, close subscriptions, onboard, retain, and expand contractor customers.

---

## Quick Start

### 1. Installation
```bash
cd revenuerecover-ai-ecosystem
npm install
```

### 2. Environment Setup
Copy `.env.example` to `.env.local` and configure credentials:
```bash
cp .env.example .env.local
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the platform.

## Autonomous Growth Organization (25 Specialized Agents)

1. **CEO / Orchestrator Agent:** Coordinates cross-agent workflows and manages the state machine.
2. **Market Intelligence Agent:** Researches contractor market signals and regional pricing dynamics.
3. **Lead Discovery Agent:** Multi-source adapter engine (Google Places, OSM Overpass, Yelp, UK Companies House).
4. **Lead Verification Agent:** E.164 phone verification, registry lookups, domain MX validation.
5. **Lead Enrichment Agent:** Fleet size signals, review metrics, estimated revenue opportunities.
6. **Lead Scoring Agent:** Explainable ICP, pain, and contactability scoring (0–100 scale).
7. **Personalization Agent:** Contextual value proposition generation.
8. **Content Agent:** Contractor guides, comparison pages, case studies.
9. **SEO Agent:** Programmatic localized keyword targeting.
10. **Paid Ads Agent:** Ad copy and audience targeting (Safety-locked: strictly requires human approval for ad spend).
11. **Email Marketing Agent:** 5-step drip sequences with automatic suppression on opt-out.
12. **SMS / Messaging Agent:** TCPA 10DLC quiet-hour-compliant messaging.
13. **AI SDR Agent:** Inbound/outbound conversation intelligence with 12 objection playbooks.
14. **AI Sales Agent:** Customized ROI proposals and plan recommendations.
15. **Demo Agent:** Interactive 4-step recovery walkthrough simulation.
16. **Appointment Agent:** Demo calendar scheduling with automated invite confirmations.
17. **CRM Agent:** Single-source-of-truth 15-stage lifecycle state machine.
18. **Onboarding Agent:** Post-payment 60-second account provisioning & 150 local leads delivery.
19. **Customer Success Agent:** Health scoring and missed-call response monitoring.
20. **Retention Agent:** Churn detection and automated salvage offers.
21. **Upsell Agent:** Pro Annual VIP expansion triggers ($990/yr).
22. **Analytics Agent:** CAC, LTV, conversion, and AI token cost accounting.
23. **Compliance Agent:** TCPA, CAN-SPAM, and GDPR pre-flight checks.
24. **Security Agent:** RBAC tenant isolation and secret protection.
25. **QA Agent:** Continuous automated smoke testing.
